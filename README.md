# 🍅 FlowTomato

> 番茄工作法 PWA，支持飞书同步

## 技术栈


## 功能

- ⏱ **番茄计时器**：标准 25/5/15 分钟，可自定义时长
- 🔔 **系统通知**：每个阶段结束时弹出 Web 通知
- 📋 **历史记录**：今日专注统计，每条记录可见飞书同步状态

- ⚙️ **灵活配置**：时长、自动开始、通知开关，设置持久化存储



## 飞书集成配置

在飞书群聊中添加「自定义机器人」：
1. 进入飞书群聊 → 设置 → 群机器人 → 添加机器人 → 自定义机器人
2. 复制生成的 **Webhook URL**
3. 打开 FlowTomato → 设置 → 飞书同步 → 填入 URL → 保存

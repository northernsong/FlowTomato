# 待办-番茄


## MVP 界面结构

主界面可以做成三层：
```
┌────────────────────────────────────┐
│  Now / 正在做                      │
│  当前任务卡片 + 开始番茄钟          │
├────────────────────────────────────┤
│  Todo / 待办                       │
│  今日待办、优先级、拖拽排序         │
├────────────────────────────────────┤
│  Done / 完成汇总                   │
│  今日完成、番茄钟次数、耗时统计      │
└────────────────────────────────────┘
```

番茄钟建议放右侧：
```
主任务区                         右侧抽屉
┌──────────────────────┐       ┌────────────┐
│ Now                  │  ←→   │ Pomodoro   │
│ Todo                 │       │ 25:00      │
│ Done                 │       │ 关联任务    │
└──────────────────────┘       └────────────┘
```

Tasks 表

## 界面风格建议

关键词：极简、卡片、毛玻璃、低饱和、macOS 原生感。

可以让 AI 按这个方向生成 UI：

设计一个优雅的 macOS 个人待办应用，整体风格类似 Linear + Things 3 + Raycast。浅色/深色模式，圆角卡片，柔和阴影，左侧或右侧可展开番茄钟抽屉。主界面分为 Now、Todo、Done 三个区域，强调当前正在做的事情。

## 节奏

第一阶段：本地假数据 + 漂亮 UI
先把界面做出来。

第二阶段：接 NocoDB API
实现读取、创建、更新任务。NocoDB 表格记录 API 支持读取和编辑表格数据，也支持按条件查询记录。

第三阶段：番茄钟 + 统计
把番茄钟记录写入 Pomodoro 表。

第四阶段：打包成 macOS app
